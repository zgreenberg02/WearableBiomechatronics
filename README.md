# WearableBiomechatronics
Mechanical hardware development for an EPIC Lab motion capture suit and lower-limb assistive devices. Includes low-profile SLA enclosures, strain-relieved routing, and rapid-donning closures for repeatable sensor placement. Features custom mounting and joint alignment for active rehabilitation and energy-harvesting exoskeletons.
